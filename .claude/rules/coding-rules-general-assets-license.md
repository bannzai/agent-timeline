# 素材のライセンス記録

外部素材 (画像・音声・フォント・3D モデル等) を `assets/` に追加する時は、`assets/CREDITS.md` に次を追記する。記録のない素材は追加しない (素材ファイルを追加する差分には、同じ PR で `CREDITS.md` の追記を含める)。

- 素材名・作者
- 入手 URL
- ライセンス (CC0 / CC-BY / OFL 等) と、クレジット表記の要否
- 改変して使っている場合はその旨 (トリミング・縮小・ファイル名変更等)
- 生成物 (画像生成 AI 等) は、生成に使ったツール・プロンプトの要点・利用規約上の帰属

## public リポジトリで守ること

- 「素材としての再配布」を禁じる規約の素材 (フリー素材サイトによくある条件) は、ファイルをリポジトリに置くこと自体が再配布に当たり得るため使わない。CC0 か、リポジトリへの同梱を規約が明示的に許す素材だけを使う
- ライセンス全文の同梱を求める素材 (OFL のフォント等) は、ライセンスファイルを素材と同じディレクトリに置き、配布物 (エクスポートの include filter 等) にも含める
- 他者の商標・原作の名称・画像・音・ロゴを使わない

## クレジット表記の確認

クレジット表記が必要な素材は、ゲーム内クレジットまたは配布先 (ストア・投稿サイト) の説明文への記載を、リリース前に「ユーザー作業の一覧」issue の確認のセクション (`~/.claude/documents/rules/record-user-only-tasks-in-single-issue.md`) で確認する。
