# 完了報告では「やらなかったこと」も明示する

## ルール

- タスクの完了報告には、実施内容に加えて次を明示する:
  - 依頼・issue の要件のうち、今回のスコープ外にした・未実装で残した範囲と、その理由
  - 定型の成果物 (PR・コミット・issue 起票など) を作らなかった場合は、その事実と理由 (例: コード変更が無いため PR なし)
- 完了報告を書く前に anything-else skill (`~/.claude/skills/anything-else/SKILL.md`) の手順で、会話ログからやり残しと答えてない質問を洗い出し、残っているものを報告に書く (起票元: https://github.com/bannzai/castle/issues/1565 )
- 明示が要るのは欠落・省略が存在する場合だけでよい。依頼範囲をすべて実施したなら追記は不要
- 未実施で残した範囲のその後の扱い (そのまま残す・issue 化する等) が自明でなければ、完了報告と同時に扱いの案を添える
- 本ルールは `~/.claude/CLAUDE.md` 規約「最後までやり切ってから完了報告する」の完遂義務を弱めない
