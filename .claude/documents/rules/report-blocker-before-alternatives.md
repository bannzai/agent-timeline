# ブロックされたらまず理由を報告する

依頼された方法が実行できない・途中でブロックされた場合、代替手段に切り替える前に、何にどうブロックされたかを先に報告する。

- 指定された実行方式を別の方式で勝手に代替しない（例: ローカルでの codex CLI レビュー依頼を `@codex review` コメント投稿で代用しない）
- 代替手段はブロック理由の報告とセットで提案し、どちらで進めるかはユーザーの判断を仰ぐ
